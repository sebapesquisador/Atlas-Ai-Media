## Prioridade 1 — Nim Proof of Production [PRÓXIMO]

Objetivo:

provar em 15–25 segundos que um provider/modelo externo consegue gerar uma
sequência que realmente seria publicável.

Teste:

- Lucas sozinho;
- Ricardo sozinho;
- ambos na mesma linguagem visual;
- movimento/reação;
- 3–4 planos.

Gate:

- identidade >= 8/10;
- continuidade >= 8/10;
- qualidade cinematográfica >= 8/10;
- movimento/anatomia >= 8/10;
- semântica >= 8/10.

Regras:

- máximo de 2 tentativas por modelo;
- não integrar API antes do PASS;
- não gerar filme completo antes do proof;
- não reabrir a rota local rejeitada.

## Prioridade 2 — Visual Provider Adapter

Somente após o proof manual passar:

- definir contrato backend-neutral;
- registrar provider/model/custo/parameters;
- integrar Nim/API se tecnicamente disponível e adequado;
- manter fallback entre modelos/providers;
- cost gate;
- fail-closed;
- zero publicação como efeito colateral.

## Prioridade 3 — Primeiro master publicável
